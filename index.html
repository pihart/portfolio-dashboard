Unlock the dashboard

Enter a fine-grained GitHub token restricted to the private dashboard repository with read-only Contents access.

1. Create restricted token on GitHub

On GitHub, choose Only select repositories, select the private dashboard repository, then generate and copy the token.

On the first successful unlock, save the credential if Passwords offers. Later, select the token field and use AutoFill or Touch ID.

The token is sent only to api.github.com. The app keeps it in this window's temporary session, never in its offline cache.
